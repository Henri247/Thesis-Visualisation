CHAPTER 02 — METHOD

From documents to case studies.

A critical-realist, deductive explanatory case-study design using secondary qualitative evidence and descriptive coding.

METHOD IN ONE SENTENCE

Look beneath observed conditions for the structures producing them.

The research uses observed working conditions as evidence, then asks what mechanisms — bargaining power, subcontracting, wage structures and historical dependence — help produce them.

Define the theoretical lenses before entering the cases.
Select two information-rich cases of externalised production.
Build each case from secondary qualitative sources.
Code documents deductively using themes identified in the literature review.
Triangulate NGO, academic and government evidence.
Contrast mainstream interpretations with critical explanations.

DATA LIMIT

The dissertation explicitly notes that missing quantitative wage, hours and productivity data limits attempts to calculate value drains numerically.
